## 3. Decisions worth remembering

- **Tracing is manual, not auto-instrumented.** The gateway needs one span per upstream
  attempt with TTFT and attempt number; auto-instrumentation cannot express that and
  monkey-patches httpx, which complicates injected test clients. See
  `notes/observability.md`.
- **Metrics are opt-in with a separate port.** Route labels use the matched template, never
  the concrete path; TTFT is a histogram because a per-request trace value cannot be
  aggregated.
- **Model access defaults to allow.** Existing deployments keep working; restriction is an
  explicit per-tenant allowlist. Empty allowlist means "no models", intentionally.
- **Costs are stored, prices are versioned.** `effective_from` rows are never edited;
  historical cost is frozen on the usage row. Money is `NUMERIC(18,6)` and `Decimal`.
- **Plans are token allowances; overage is a switch.** Inside the plan is free, above it is
  list price. `plan_allow_overage=false` blocks at exhaustion; `true` bills overage and the
  cost budget is the hard cap.
- **No pre-call reservation.** Accepted overshoot is bounded by in-flight requests; recorded
  as a non-goal with the condition that would justify revisiting it.
- **Admin audit is best effort.** The action already happened; a failed audit write is
  counted and logged, never silently dropped. Only business fields are stored.
- **Master key stays as break-glass owner.** Sessions are the browser credential, CSRF is a
  double submit, and disabling the master key requires an existing owner or startup fails.
- **Prompt limits are character budgets.** No provider tokenizer exists; the error names the
  field so clients can react.
- **Deployment credentials are environment variable names.** No secrets in the database; the
  pool resolves and caches clients per `(provider, env var, base_url)`.
- **Cooldown is process-local.** Shared health belongs with the Redis work (G1.2); a cooldown
  never removes the last candidate.
- **Provider retries stay inside a deployment.** Failover happens after them; lower
  `GATEWAY_MAX_RETRIES` for faster switchover.
